# Sales Analytics Dashboard

An interactive sales dashboard built with **MySQL, Power BI, DAX and Power Query**.

## Dashboard Preview
![Dashboard](Screenshot%202026-11-12%20205758.png)

## What this project does
- Connects a MySQL sales database to Power BI
- Cleans and transforms data using Power Query
- Uses a Calendar table and DAX measures for time-based analysis
- Shows KPI cards, monthly sales trend, sales by category, top 10 products and sales by region
- Includes Year, Region and Segment slicers

## DAX Measures
Total Sales, Total Orders, Total Customers, Avg Order Value, Sales LY, YoY Growth %, Avg Shipping Days

## Key Insights
- West is the top region by sales (about 31%), and South is the lowest (about 17%)
- Technology is the highest-selling category
- Canon imageCLASS 2200 Advanced Copier is the top product
- Sales tend to rise in the last months of the year

## Tools Used
MySQL, Power BI Desktop, DAX, Power Query
